Settlement is now deterministic: tasks spawned by a dispatched event are joined to completion — including executor/thread-backed work (`run_in_executor`, `asyncio.to_thread`, aiosqlite) that schedules nothing on the event loop. Previously such work was misclassified as parked and abandoned mid-flight, so actor verbs could return while the bot was still reacting.

Only explicitly recognized external input may remain parked: `Client.wait_for`, View/Modal completion, standard awaitable composition, verified far-future sleeps, and `await env.external_wait(awaitable, reason=...)`. Unknown waits time out. Ownership survives timeout, cancellation, later operations, restart, and teardown; overlap is rejected before mutation and caller tasks survive teardown.

Breaking: The unreleased coroutine-name parking option and prior ownership reconstruction are removed. Python 3.12+ is required; CI exercises 3.12, 3.13, and 3.14.
