Settlement is now deterministic: tasks spawned by a dispatched event are joined to completion — including executor/thread-backed work (`run_in_executor`, `asyncio.to_thread`, aiosqlite) that schedules nothing on the event loop. Previously such work was misclassified as parked and abandoned mid-flight, so actor verbs could return while the bot was still reacting.

Tasks are left running only when provably waiting on future input: discord.py background machinery (View timeouts, `wait_for` listeners) or their own far-future `asyncio.sleep` timers (use `env.advance_time()`). Anything else that cannot progress raises a `TimeoutError` naming the dispatched event and the stuck tasks, with a hint pointing at the new `Env(background_names=...)` option for intentionally-parking handlers.

Breaking: handlers that previously outlived an actor verb now block it; Python 3.12+ is required.
